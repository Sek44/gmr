# ADR transversaux

Ce répertoire accueille les *Architecture Decision Records* qui concernent l'ensemble de GMR ou plusieurs jeux. Une décision locale appartient à `games/<id>/docs/adr/`.

Conventions : `0001-titre-court.md`, un sujet par fichier, sections **Contexte**, **Décision**, **Conséquences** (et **Options envisagées** si utile), avec date et statut **Proposé**, **Accepté** ou **Remplacé**.

Un ADR accepté décrit une décision prise à une date donnée ; il n'est pas réécrit pour masquer une décision antérieure. Si elle change, ajouter un ADR et relier les deux. Seuls les documents `ARCHITECTURE.md` décrivent l'architecture courante.

Premier exemple réel : [ADR GCV — progression unique des tours](../../games/gcv/docs/adr/0001-progression-des-tours.md).
